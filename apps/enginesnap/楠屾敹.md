## 四、本轮撞到并记下的语言边界（顺带升级的产物）

1. **全局变量不支持指针类型**（`int*` / `char*` / `double*` 全局都编不过，编译器原文：「暂不支持指针类型的全局变量——第一版只开 int / char / double 标量与数组」）
   → 路径这类常量不做全局，直接在调用点用字符串字面量。
2. **源文件必须纯 ASCII** → 快照文件名取 **ASCII**（`state-snapshot.txt`）；中文只出现在**内容**里，运行时转码显示（否则要为路径名上 GBK 字节表那一套）。
3. **函数参数上限 4 个**（本轮我又踩一次：`dump_state` 写了 10 个参数被拦下）→ 诊断量走全局变量/结构体。
4. **中文显示不需要自己写码表**：`MultiByteToWideChar(CP_UTF8)` → `WideCharToMultiByte(CP_ACP)` 两步即可（本机 ANSI = GBK，`*A` 家族 API 直接能画）。
5. **少了 `DispatchMessageA` 会让消息循环变死循环**（`ValidateRect` 不执行 → WM_PAINT 反复入队；进程活着但一帧不走）。
6. 🔴 **boot 侧 API 实参上限没跟上真 flint**（真 flint v1.4.0 已 12→16，boot 侧仍是老上限）：
   `CreateFontA`（14 参）在 boot 侧直接 `parse err=-175` ⇒ **整个 `ui_lib` 在 boot 侧不可用**，双端覆盖断在这。
