> **一句话概述**（这门语言的形状，按重要程度排）：
> - **语法是 C 的子集，类型层不是**：`int`（32 位，v1.7.0 起 4 字节元素）/ `int_32`（`int` 别名）/ `int_64`（64 位）/ `char`（无符号字节）/ `double` 五种，**没有泛型**、**没有无符号整型**、**没有异常**、**没有 `sizeof`**、**没有 C 风格转型**。
> - **`int` 各处宽度**：字面量/算术 = **32 位**（十进制 > 2147483647 自动升级成 `int_64` 字面量；`2147483647 + 1` 回绕成 `-2147483648`），数组元素 = **4 字节**（本地/全局/struct 同一口径；标量栈槽 8 字节只是实现细节），`struct` 字段 = 真实 C 布局（`int` 4 字节），指针下标 `p[i]` = **步长 4 / 读出宽 4**，裸指针 `p ± n` = **字节步进**（所以 `p[i] ≠ *(p+i)`）；`int_64` 则值宽=槽宽=步长=8。拆字节一律 `% 256` + 负数兜底。速查表 ＋ 逐条探针见 `docs\设计决策.md` **D10**（台账 F-035～F-041）。
> - **函数参数 ≤ <!--fact:limit-funcargs-->32<!--/fact-->**（前 4 个走 `rcx/rdx/r8/r9`，`double` 走 `xmm0-3`，第 5 个起走栈参，求值顺序**右→左**）。
> - **`struct` 字段 ≤ <!--fact:limit-structfields-->128<!--/fact-->**（2026-09-27 由 64 抬到 128）。
> - **导入表硬上限 <!--fact:limit-imports-->96<!--/fact--> 条 API ／ <!--fact:limit-groups-->8<!--/fact--> 个 DLL 分组**；**导入模块名（写出名）≤ <!--fact:limit-dllname-->63<!--/fact--> 字节**（含自动补的 `.dll`；2026-10-13 B1-3 起超长是**默认档编译期硬错**）；**boot（自举编译器）的函数表 <!--fact:boot-limit-->512<!--/fact--> 项，当前余量 = <!--fact:boot-headroom-->5<!--/fact-->**（2026-10-15 复测；2026-10-13 曾为 0 —— 加库函数前先跑 `tools\boot余量.ps1`）。
> - **非 ASCII 文本不能做字面量**：中文要走「UTF-8 源 → GBK 逐字节十六进制表 → 生成器 → 自检」这条链，**每个标签一个构建步骤**。
>

## 0. 三类结论怎么读

探针把每条用例归成三类，**每类都有实质断言**（不是"编译成功就算过"）：

| 类别 | 本文写法 | 含义 | 怎么算过 |
|---|---|---|---|
| `ok` | **支持** | 语言**支持**这件事 | 必须编过，**且产物退出码 == 期望值**（支持这件事也得行为对） |
| `wall` | **明确拒绝** | 一座**明确挡住的墙** | 必须**编译失败**，且错误文案里含关键词 |
| `gap` | **已知静默缺口** | 已知的**静默**缺口（编译过、行为不对） | 必须**能编过** —— 一旦有人修好它，这条会**变红**，提醒回来订正本表 |

⇒ 这套设计的要点：**放宽了会红、收紧了也会红**。所以本表"过期"这件事是**可被发现**的，不用靠人记得。
