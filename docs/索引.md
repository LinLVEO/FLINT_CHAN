## 两条路径（先看你属于哪一类）

| 你是 | 读这几项 | 读完能干什么 |
|---|---|---|
| **① 只想用它写点东西** | **前三项**：`README.md` → 快速上手 → `docs\语言边界.md` | 装上、跑通第一个程序、知道哪些写法会撞墙 |
| **② 想参与（报 bug / 提判据 / 一起定方向）** | **后三项**：`PROGRESS.md` → `docs\协作协议.md` → `SPEC.md` | 知道现在做到哪了、怎么和我们一起干活、设计权威在哪 |

> 中间两项（`docs\设计决策.md`、`开源前-人类可用性缺口.md`）是**"想参与"的入口**：前者给讨论的抓手（"我有意见的是 D几"），后者是**我们自己的缺点账**（先看它再提意见，能省你一半时间）。
