# FLINT 的真实项目（每个数字都实测过）

> 本页所有数字都是**在仓库根目录 `E:\FLINT-lab` 当场测的**，不是从别的文档抄的。
> 测量时间：**2026-10-13 21:2x ~ 21:4x**；编译器 = 仓库根目录的 `flint.exe`（**250,064 字节**；
> 版本号 **v1.4.28**，出处 = `flint.exe` 自己的用法输出里 `-gui … （v1.4.28）` 那一行 ＋ `README.md` 的事实表）。
>
> **行数口径**（很重要）：用 `[IO.File]::ReadAllLines($p).Count`。
> 本机 PowerShell 5.1 的 `Get-Content` 默认按 **ANSI(GBK)** 解码，而 `.fl` 源码是 **UTF-8**：
> 一个 UTF-8 多字节字符的尾字节（≥0x80）正好落在 GBK 的首字节区间，会把**紧跟其后的换行吃掉**——
> 实测把 263 行的 `ui_gallery\main.fl` 读成 201 行、把 1,048 行的 `winpanel\验收.md` 读成 596 行。
> 凡是"源码多少行"的数字，都不要用 `Get-Content | Measure-Object -Line`。
>
> **产物字节**：`(Get-Item $p).Length`。**重编核对**：把文档里的命令 `-o` 到 `tmp\` 复跑，再和仓库里的产物比 SHA256。

## 1. `apps\winpanel` —— 旗舰工具（桌面面板）

- **是什么**：单文件、无运行时依赖的桌面面板工具。1024×736 无边框分层窗口：标题栏（折叠/最小化/Setup/主题/×）+ 7 页导航（本地/端口/自身/启动/操作/系统/环境）+ 二级 Settings 页（含真正驱动整窗 alpha 的不透明度滑块）。数据来源是**三路真东西**：每 2 秒重读一次的状态快照文件、真实 TCP 端口探测（非阻塞 select）、4 条**只读**注册表项。
- **用哪些库**：`lib\flgui_win32.fl`（FLGUI 平台层：窗口/表面/ULW 上屏；它自己再 include `flgui_widgets.fl`、`ui_lib.fl`）＋ app 自己 include `io_lib.fl`、`http_lib.fl`。
- **源码规模（实测）**：`apps\winpanel\main.fl` = **5,242 行 / 266,036 字节**（另有两张语言表 `lang.zh.txt` 841 B、`lang.en.txt` 821 B，中文文案在表里、源码本身是纯 ASCII）。
- **产物（实测）**：`apps\winpanel\winpanel.exe` = **353,792 字节**，PE 子系统 = **2（Windows GUI）**。
  重编核对：`flint.exe apps\winpanel\main.fl -gui -o <tmp>\winpanel_gui.exe` → exit 0、353,792 字节、SHA256 前 16 位 `152B9EC1959CB02D`，与仓库里那份**逐字节相同**。
- **怎么跑（实测过）**：
  ```cmd
  cd /d E:\FLINT-lab
  flint.exe apps\winpanel\main.fl -gui -o apps\winpanel\winpanel.exe
  apps\winpanel\winpanel.exe
  ```
  ⚠️ **`-gui` 不能漏**：漏掉会得到子系统 = 3 的产物（字节数一样 353,792，但运行时会多开一个控制台黑窗）。
  实测对照：带 `-gui` = `subsystem 2 / sha 152B9EC1…`，不带 = `subsystem 3 / sha ED8CCFE4…`。
- **判据（114 条，在哪）**：`apps\winpanel\verify-panel.ps1`（**3,307 行**）里有 **114 个不同的判据编号**——
  `Check "C…"` 调用点共 **116 处**（其中 `C6x4` 出现在三选一的分支里 3 次，单次运行只会走到一条）。
  这套判据绝大多数是**真鼠标 / 真键盘**（真点导航、真拖标题栏、真点滑块、真按热键）。结论与逐轮数字见 `apps\winpanel\验收.md`（**1,048 行**）。
  **我没有跑这道门**：工单明确禁止（114 条真鼠标判据要求桌面干净），我只做了**静态计数**。

## 2. `apps\ui_gallery` —— FLGUI 控件画廊

- **是什么**：一屏把 FLGUI 的控件摆齐的最小画廊（420×260 无边框窗口）：按钮 / 勾选 / 单选 ×2 / 进度条 / 滑块 / 可编辑文本域 / 带滚动条的滚动视图。它的价值是"控件矩形被硬编码坐标的真鼠标探针钉住"，所以换实现时同一套判据仍然有效。
- **用哪些库**：只 include `lib\flgui_win32.fl`（连带 `flgui_widgets.fl`、`ui_lib.fl`）。
- **源码规模（实测）**：`apps\ui_gallery\main.fl` = **263 行 / 12,721 字节**。
- **产物（实测）**：`apps\ui_gallery\ui_gallery.exe` = **146,944 字节**，PE 子系统 = **3（Windows CUI）** ⇒ 运行时**会同时出现一个控制台窗**（源码里的 `win.cls` 是 `FLINTGAL`）。
  重编核对：`flint.exe apps\ui_gallery\main.fl -o <tmp>\ui_gallery.exe` → exit 0、146,944 字节、SHA256 `F437229A91837EA442F6388C7786410B0880C7BF25A181997846E7029D4DA203`，与仓库里那份**逐字节相同**。
- **怎么跑（实测过）**：
  ```cmd
  cd /d E:\FLINT-lab
  flint.exe apps\ui_gallery\main.fl -o apps\ui_gallery\ui_gallery.exe
  apps\ui_gallery\ui_gallery.exe
  ```
  关窗 = 在窗口上点**右键**（FLGUI 的消息泵只认 `WM_QUIT`，这个 app 靠 `GetAsyncKeyState(2)` 轮询右键）。
- **判据（19 条，在哪）**：三个**真输入**探针，都在 `apps\ui_gallery\`：
  `mouse-test.ps1` **4 条**（真鼠标点控件，断 `btn=2 chk=1 scr=…`）、
  `drag-probe.ps1` **8 条 / 轮**（真鼠标拖标题栏、双击最大化等，可加轮）、
  `wheel-probe.ps1` **7 条**（真滚轮，一格 = 60px、到底夹住）。
  同族的库级门是 `test\flgui-verify.ps1`。**这三个探针我都没跑**：都要真键鼠 + 桌面安静（工单禁止）。

## 3. `apps\m2_float` —— 硬件监视浮窗

- **是什么**：TOPMOST + LAYERED + 无边框的硬件读数浮窗，8 行（FPS / CPU / GPU / RAM / DISK / NET / FAN / 功耗），窗口尺寸按行内容自适应（实测 187×168），右键弹中文菜单，位置与开关存 `config.json`。数据由**同进程缝合**的 C# LHM 桥给（`HwBridge.dll` 走导入表直调）。
- **用哪些库**：`lib\flgui_win32.fl`（→ `flgui_widgets.fl` / `ui_lib.fl`）＋ 自己的 8 个模块 `hw.fl`、`stitch.fl`、`float_rows.fl`、`menu.fl`、`menu_gen.fl`、`config.fl`、`netfmt.fl`、`glyph.fl`（它们再拉 `lib\` 的 `math_lib.fl`、`http_lib.fl`、`fmt_lib.fl`、`num_lib.fl`、`str_lib.fl`、`io_lib.fl`、`ui_lib.fl`）。
- **源码规模（实测）**：`apps\m2_float\*.fl` 共 **2,942 行 / 145,165 字节**（其中 `main.fl` = **796 行 / 45,330 字节**）。
- **产物（实测）**：`apps\m2_float\m2_float.exe` = **241,664 字节**，子系统 = 3（CUI），**内嵌 `requireAdministrator` 清单**。
  同一个源不带 `-admin` 重编 = **241,152 字节**（差的 **512 字节**就是那份清单；两次都 exit 0）。
- **怎么跑（实测过，且**踩到真问题**）**：
  ```cmd
  cd /d E:\FLINT-lab
  flint.exe apps\m2_float\main.fl -admin -o apps\m2_float\m2_float.exe
  apps\m2_float\m2_float.exe
  ```
  ⚠️ **实测：直接跑这份产物会崩**。事件日志里两条一样的记录（21:29:05、21:30:19）：
  `m2_float.exe` 在 **`atiadlxx.dll`**（AMD 厂商库）里 **`0xC0000005`**，fault offset `0x7ed5c`——
  所以窗口建出来是 **200×130 的空窗、从不绘制**（`PrintWindow` 返回 False、非背景像素 = 0）。
  **这是已知问题，不是新缺陷**：`test\loop-verify.ps1` 头注释写得很清楚——清了产物 PE 头的
  `DYNAMIC_BASE|HIGH_ENTROPY_VA` 就好，"原因不在代码生成，是这台机器有 AMD GPU，`atiadlxx.dll`
  在镜像被随机基址加载时 0xC0000005（只翻那两个字节、不重编就能换过/不过）"。
  我按这个做法复刻了一份（**清位 0x0160 → 0x0100**）+ 去掉 `-admin`（否则见下面的 UIPI 边界），
  窗口正常长到 **187×168** 并画出 8 行读数 ⇒ 图 `docs\图片\m2_float-浮窗.png`。
  另一条实测边界：**带 `-admin` 的产物跑在提升会话里时，非提升的抓图进程 `PrintWindow` 一律返回 False**
  （UIPI 拦 `WM_PRINT`）——只有去掉清单、两边同一完整性级别才抓得到。这正好是上面"复刻"的第二个理由。
- **判据（9 条，在哪）**：`test\loop-verify.ps1`（**312 行**）——真应用端到端冒烟门：用 `flint.exe` **和**自举编译器
  `boot\b1_emit.exe` 各编一遍 `apps\m2_float\main.fl`，清 ASLR 位，用 app 自己的 `dump.on + demo.on` 自检开关跑起来，
  再把两份 dump **逐字节**比（掩掉 `tick=` / `dp=` 这类活值），**9/9**。
  用法与出处：`lib\FLGUI.md` §"浮窗冒烟（loop 线）" = `pwsh -File test\loop-verify.ps1`。**我没跑**（工单禁止长套件）。

## 一句话总结"外人看得见"的部分

三个 app 都是**一个源码目录进、一个单文件 exe 出、没有安装器也没有运行时依赖**；
`winpanel` 与 `ui_gallery` 的产物我已经用文档里的命令**逐字节复现**过；
`m2_float` 的源码也编得过、跑得起来，但**仓库里那份产物在这台 AMD 机器上会被厂商库的 ASLR 崩溃挡住**
（项目自己的门是清位绕过的）。这就是目前真实的边界，没有藏。
